1. CSS Masks CSS Only
Uses CSS mask properties to apply optimized SVGs dynamically. Sizing is inherited from the parent font-size, and coloring uses currentColor. Works for all styles, including multi-color duotone masks. 
<span class="stria-solid stria-gear"></span>
2. Webfont (Icon Font) CSS Only
Renders icons via traditional @font-face content injection (like FontAwesome). Uses Unicode characters mapped to custom font glyphs. Sizing and coloring behave like regular typography. Duotone is excluded. 
<i class="st-solid st-gear"></i>
3. SVG Sprites No JS / No Font
Loads icons inlining SVG references via <use> pointing to the style's sprite sheet. Very performant, scales perfectly, and doesn't suffer from font load delays. 
<svg class="stria-icon" fill="currentColor">
  <use href="dist/sprites/solid.svg#gear"></use>
</svg>
4. Javascript Replacer API Dynamic JS
Uses stria.replace() API to scan the DOM and replace placeholders containing the specified attributes into inline, styled SVGs. Re-renders clean inline vector paths. 
<i data-stria="gear" data-stria-style="solid"></i>
<script>
  stria.replace();
</script>
